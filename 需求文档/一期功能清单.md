# AI 译评平台 & Admin · 一期功能清单

> **v1.7 · 2026-06** — 简版，供评审和对齐用。  
> 详版：《双平台功能列表-一期》、《PRD-译评平台-一期》v1.14、《PRD-Admin管理平台-一期》。  
> **工作台原型（合并）**：`AI 译评平台 & Admin/eval-prototype/`（`prototype/` 自动跳转）

**目标**：新语种按 SOP（约 3.5 天）跑通——在译评平台写 Prompt、跑评测、看报告并由专家标可用后，经 Admin 发布到测试/预发/正式，译配运行时自动读配置，**不再改代码发版**。

## 0. 已确认决策（汇总）

| 项 | 结论 |
|----|------|
| 可用判定 | **一期人工**：专家标可用/不可用；系统只出**分析/对比报告** |
| 自动过线 | **二期**；一期不做规则配置 UI |
| AI 建议版本 | **后续**：报告/列表展示「建议采用 vN」；**不**自动标可用 |
| Prompt 槽位 | `system` / `name_mapping` / `engineering` |
| Prompt 撰写 | **结构化分槽 P0**（原型）；Markdown 入口 **P1** |
| 登录 | **一期不做** |
| 访问 | **仅公司内网 VPN** |
| Admin Gate | **仅译评专家标「可用」可提交**；Admin **不展示** gate |
| Admin Web | 见 Admin PRD **§7.2.6** + `eval-prototype/` |
| 双译文称谓 | 产品/UI：**平台翻译 / 人工校对**；JSONL 字段 `t0`/`t1` 仅为数据层兼容（见译评 PRD §7.1.1） |
| 译配更新配置 | **消息（主）+ 轮询（兜底）** + 本地缓存 etag |
| **产品形态** | **一个工作台、两个模块、两块后端**（详见《双平台功能列表》§1） |

### 双译文评测（平台翻译 vs 人工校对）

评测时每一句字幕包含：**原文** + **平台翻译** + **人工校对** 两版译文；裁判分别打分（数据层为 `score0` / `score1`），比较平台版能否打平或超过人工底稿。  
**不再**使用「t0/t1」作为面向业务的产品称谓（与 `system_v1.md` 汇总报告一致）。

## 1. 语种工作台（一个入口 · 两个模块）

| 模块 | 干什么 | 不干什么 | 后端 |
|------|--------|----------|------|
| **质量迭代**（原译评） | 写语种规则、跑评测、分析/对比报告、专家标可用、提交入库 | 多环境发布、Config API | **迭代服务** |
| **配置发布**（原 Admin） | 语种壳、版本库、测试/预发/正式发布与回滚 | 写 Prompt、跑评测、登录权限 | **配置服务** |

**主链路**：迭代（写 + 评 + 可用）→ 配置（入库 + 发环境 + 通知）→ 译配（缓存读配置）  
**一期工程**：前端可先合并 **工作台壳** + 同语种详情路由；API 仍两套，经 BFF 或直连聚合。

## 3. Admin（全新）

| 功能 | 说明 | 优先级 |
|------|------|--------|
| 语种管理 + 详情（**VPN**） | `#/config` · 列表：**语种**、语对、**应用阶段**、已入库、负责人；详情：环境摘要 + 发布 + **Prompt 版本** + 历史 | P0 |

| **发布/回滚 → 消息通知译配** | P0 |

## 4. 译配（对接）

Admin 发布后，译配拿新 Prompt 的方式（**两种都要做**）：

| 方式 | 角色 | 说明 |
|------|------|------|
| **消息通知** | 主路径 | Admin 发布/回滚 → 发消息 → 译配清缓存 → 立刻拉新配置（目标 ≤10s） |
| **轮询** | 兜底 | 每 5–15min 带 etag 问 Admin；没变返回 304，变了就拉新配置 |
| **本地缓存** | 基础 | 按语种+环境缓存；所有请求都带 etag，减少重复拉取 |

详版见 **Admin PRD §7.2.4**。

---

## 5. 验收标准

1. 新语种 Prompt 上测试环境：**零代码发版**  
2. 每版上线 Prompt：**≥1 份评测报告 + 过线结论**  
3. 阶段 2 对比 + 一轮优化：**≤1 工作日**（试点范围）  
4. Admin 发布后译配：**消息路径 ≤10s** 或轮询周期内生效
